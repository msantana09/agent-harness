# Security

This repository includes hooks and scripts that execute commands on your machine.

Codex jobs have network access and may receive a GitHub token. The read-only sandbox restricts local
file changes; it does not restrict GitHub API actions permitted by that token. See
[network and GitHub access](skills/codex/references/jobs.md#network-and-github-access) for details.

Report vulnerabilities privately through **Security → Report a vulnerability**
on this repository. Please do not report vulnerabilities in public issues.
